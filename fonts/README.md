# Fontes necessárias

Coloque nesta pasta os arquivos `.ttf` (ou `.otf`) das duas fontes da marca:

1. **Gallient** — fonte serifada usada nos títulos/ideia central.
   Você precisa fornecer o arquivo da fonte (verifique a licença de uso: precisa
   permitir "embedding"/uso em aplicações, não só uso pessoal em editores de design).
   Nomeie o arquivo, por exemplo: `Gallient-Regular.ttf`.

2. **Montserrat** — fonte usada no @ do topo, textos de apoio e tagline.
   É uma fonte gratuita (licença Open Font License). Baixe em:
   https://fonts.google.com/specimen/Montserrat
   Baixe pelo menos os pesos Regular e Bold (ex: `Montserrat-Regular.ttf` e
   `Montserrat-Bold.ttf`).

O sistema carrega automaticamente todos os arquivos `.ttf`/`.otf` que estiverem
nesta pasta — não precisa editar nenhum código, só colar os arquivos aqui.

Se a Gallient não for encontrada aqui, o sistema usa uma fonte serifada do
sistema como substituta temporária, então os primeiros testes ainda vão
funcionar (só não vão ficar com a fonte exata até você adicionar o arquivo).
